# Amadeus

Голосовой ассистент с локальным desktop-интерфейсом на Electron и React и Python-бэкендом. Поддерживает текстовый и голосовой ввод, несколько чатов и вызов внешних функций.

## Возможности

- Текстовый и голосовой интерфейс
- Работа с несколькими чатами (создание, переключение, удаление, переименование)
- Русский и английский языки интерфейса и ответов ассистента (выбираются в настройках)
- Function calling (вызов функций через ИИ)
- Распознавание речи через Vosk
- Синтез речи через Piper,Microsoft TTS Edge TTS
- Установка будильников
- Получение информации о погоде
- Поиск в интернете
- Получение текущего времени

## Технологический стек

- Python 3.11
- Electron + React (desktop-интерфейс)
- Vite (сборка React renderer)
- Python JSON-lines bridge (связь интерфейса с существующим backend)
- OpenAI API (LLM)
- Vosk (распознавание речи)
- Piper TTS (синтез речи)
- Sounddevice (аудио)

## Установка

1. Клонируйте репозиторий:
```bash
git clone <url-вашего-репозитория>
cd Amadeus
```
# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt

# Установите frontend-зависимости
npm install

## Настройка

Перед запуском необходимо настроить файл `config.py`:

1. Откройте `config.py`.
2. Вставьте ваш API ключ в переменную `API_KEY`.
3. При необходимости измените `BASE_URL` (если используете прокси) и `AI_MODEL`.

## Запуск

Запуск desktop-окна Electron с Vite для разработки:

```bash
npm run dev
```

Запуск собранного React-интерфейса в desktop-окне (без открытия внешнего браузера):

```bash
npm start
```

Python запускается как отдельный локальный процесс. По умолчанию приложение использует `venv` из корня репозитория; можно указать другой интерпретатор через переменную `AMADEUS_PYTHON`.

## Использование

### Текстовый режим

1. Введите текст в поле ввода внизу экрана.
2. Нажмите Enter или кнопку отправки.
3. Дождитесь ответа ассистента.

### Голосовой режим

1. Нажмите кнопку "Голос" для активации микрофона.
2. Произнесите слово активации "Амадэус".
3. Задайте вопрос голосом.

### Управление чатами

- Кнопка "+" в боковой панели — создать новый чат.
- Три точки справа от названия чата — меню (переименовать или удалить).
- Клик по названию чата — переключиться на него.
- Кнопка меню (гамбургер) в левом верхнем углу — скрыть или показать боковую панель.

## Desktop-архитектура

- `desktop/electron-main.cjs` создаёт нативное desktop-окно и запускает Python-процесс.
- `desktop/preload.cjs` открывает renderer только узкий API команд и событий через `contextBridge`. Node.js отключён в renderer, включены `contextIsolation` и sandbox.
- `src/` содержит React-интерфейс; он не обращается напрямую к файловой системе или Python.
- Чаты в `data/chats.json` разделяются по режимам `assistant` и `kurisu`; старые чаты автоматически относятся к обычному режиму.
- Выбранный язык хранится в локальном `data/settings.json` и применяется к интерфейсу, системному промпту и ответам встроенных инструментов.
- В режиме Курису справа отображается спрайт-персонаж. В сборку включены только выбранные кадры из `assets/character/`; исходная локальная папка `sprites/` не включается.
- `desktop/backend_server.py` принимает и отправляет JSON Lines через stdin/stdout. Каждое сообщение протокола помечено префиксом `@@AMADEUS@@`, чтобы обычные диагностические логи Python не путались с сообщениями интерфейса.
- `core/` остаётся Python-бэкендом. История чатов хранится локально в `data/chats.json`, а будильники — в `data/alarms.json`. Локальные данные не следует добавлять в Git.
- Изображения интерфейса хранятся в `assets/images/`.

### Правила UI-разработки для этого проекта

- Оставляйте React renderer декларативным: состояние интерфейса храните в React, side effects — в обработчиках и `useEffect`, DOM обновляйте через React, не вручную.
- Держите Electron API в main/preload. Не включайте `nodeIntegration` и не предоставляйте renderer произвольный IPC или доступ к файловой системе.
- Общайтесь с Python только через именованные команды `api.command(...)` и типизированные события `api.onEvent(...)`; не передавайте произвольные shell-команды.
- Долгие операции выполняйте в Python worker thread, не блокируя Electron event loop или renderer. UI меняйте только через события backend.
- Фиксируйте размеры только там, где они являются частью дизайна. Используйте flex/grid для адаптивной раскладки и проверяйте обычный и развёрнутый размер окна.
- Для локальной разработки используйте системные шрифты и локальные ресурсы, чтобы интерфейс не зависел от внешней сети.
- Проверяйте отдельно `npm run build`, Python syntax и запуск desktop-окна. Успешная сборка Vite не доказывает, что Python-процесс доступен или команды IPC работают.

### Текущее ограничение прототипа

Desktop-оболочка запускается из рабочего репозитория и использует установленный Python/`venv`, локальные модели и настроенный `config.py`. Самостоятельный установщик Windows, включающий Python, модели Vosk/Piper и автоматическую настройку конфигурации, пока не собирается.
